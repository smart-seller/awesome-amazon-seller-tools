## フィードバック＆レビュー
- [AMZFinder](https://www.amzfinder.com/) - AMZFinder は Amazon セラーツールのための独立したレビュー・比較プラットフォームです。8 つのコアワークフロー（商品リサーチ、キーワードリサーチ、出品最適化、価格改定、PPC、分析など）にわたってツールを整理し、各ツールを一貫したスコアカードで評価し、セラーの売上ステージに応じた事前構築済みのスタックを推奨します。これにより、セラーは重複したサブスクリプションを避け、自社のビジネスに適したツールを見つけることができます。
- [FeedbackExpress](https://www.feedbackexpress.com/) - FeedbackExpress は Amazon やマルチチャネルのセラーが、Amazon、eBay、Trustpilot などのマーケットプレイスにわたって好意的なレビューを増やし、フィードバックを管理するのを支援します。スマートな選択的レビューリクエスト、自動化されたネガティブフィードバック処理、複数の販売チャネルにわたるレビューを管理する一元化されたダッシュボードを備えています。
- [Feedbackwhiz](https://www.feedbackwhiz.com/) - 自動化されたレビュー／フィードバックのメールリクエスト、出品ハイジャッカーのアラート、利益／経費の追跡をカバーする Amazon および Walmart 向けオールインワンのセラープラットフォームです。主要な Amazon のグローバルマーケットプレイスすべてに対応しています。
- [Feedback Genius](https://www.sellerlabs.com/products/feedback-genius/?fp_ref=poly61) - Seller Labs の Feedback Genius は、Amazon セラー向けに Amazon ポリシーに準拠したレビューリクエストとセラーフィードバックのアウトリーチを自動化します。このツールは、事前構築済みまたはカスタムのテンプレートを使用して自動化された購入者メッセージを送信し、手動のフォローアップにかかる時間を節約します。
- [xSellco](https://www.xsellco.com/feedback?utm_source=affiliate&utm_campaign=493ad7f6d045d3dcea1a399c4aa06d27&utm_medium=Link+Share) - xSellco は、Amazon、eBay、Walmart などの主要なマーケットプレイスにわたって、カスタマーサポート（eDesk）、自動価格改定、フィードバック／レビュー管理のためのツールを提供する、接続された eコマースプラットフォームです。

## マーケティング＆最適化
- [ZonGuru](https://zonguru.com/) - ZonGuru は AI を活用した Amazon セラープラットフォームで、商品リサーチ、出品最適化、キーワード追跡、ビジネス指標、顧客エンゲージメントのためのツールを提供します。その Helix 出品エンジニアリング機能は、エージェント型 AI を活用して Amazon の COSMO および Alexa for Shopping の発見アルゴリズム向けに最適化します。
- [DataHawk](https://datahawk.co/) - DataHawk は Amazon、Walmart などのチャネル向けの統合マーケットプレイス分析プラットフォームで、日次の SKU レベルの売上、広告、SEO、在庫分析を提供します。AI を活用した診断と、代理店や大企業のセラー向けのホワイトラベルレポートが含まれています。
- [River Cleaner](https://rivercleaner.com/) - River Cleaner は、Amazon セラーが商品出品を自動的に最適化できる Chrome 拡張機能です。機能には、競合のキーワードの発見、キーワードがインデックスされているかの確認、重複キーワードの削除、最良および最悪のパフォーマンスの PPC キャンペーンの発見、任意のカテゴリの最大注文数量の設定、購入者名による注文の検索、TOS 変更アラート、モバイル出品プレビューが含まれます。River Cleaner は Amazon の利用規約に準拠しています。
- [AMZDataStudio](https://amzdatastudio.com/) - AMZDataStudio は、キーワード順位トラッカー、HTML 出品コンバーター、キーワードリサーチユーティリティを含む Amazon セラーツールのスイートを提供します。主に無料の Chrome 拡張機能として配布されており、Amazon 出品の最適化やキーワードインデックスの監視を望む 50,000 人以上のアクティブユーザーにサービスを提供しています。
- [SellerApp](https://www.sellerapp.com/) - SellerApp（旧 SellerPrime）は、18 以上のマーケットプレイスにわたって商品リサーチ、キーワード追跡、出品最適化、PPC 管理、利益分析をカバーするオールインワンの Amazon セラープラットフォームです。
- [Helium 10](https://i.helium10.com/c/1793920/3743859/37271) - Helium 10 のツールは、時間を節約し、収益性の高い商品を見つけ、収益性の高いキーワードを発見し、不要なキーワードを削除し、破損／紛失した在庫に対する FBA 返金を特定し、商品出品を最適化するように設計されています。Helium 10 は競合を監視し、商品トレンドを分析して、マーチャントが Amazon のプライベートラベルビジネスを拡大する機会を生み出します。
- [AMZ.One](https://www.amz.one/) - AMZ.One は、キーワード順位追跡、出品最適化分析、ハイジャックアラート、ネガティブレビュー通知、競合の売上追跡を提供するオールインワンの Amazon セラープラットフォームです。サブスクリプションプランは月額 20 ドルから始まり、17 以上の Amazon マーケットプレイスに対応しています。
- [AMZBase](https://www.amzbase.com) - AMZBase は Amazon FBA セラー向けの教育リソースハブで、サードパーティのセラーツールを厳選し、商品リサーチ、キーワード戦略、出品最適化、AI 商品撮影をカバーするステップバイステップのガイドを公開しています。Jungle Scout や Helium 10 などのツールの詳細なレビューと実践的なワークフローフレームワークを備えています。
- [AMZBase Extension](https://chromewebstore.google.com/detail/amzbase-free-amazon-produ/nhebfnlghmjfcammdgbgfcomeonbfcfn) - ASIN、ベストセラーランク、FBA オファー価格、セラー数を Amazon の検索ページやカテゴリページに直接オーバーレイ表示する、Amazon 商品リサーチ用の無料 Chrome 拡張機能です。商品画像にカーソルを合わせると、CamelCamelCamel の価格履歴と Keepa のランク履歴チャートをプレビューできます。20 以上の Amazon マーケットプレイスに対応しています。
- [AMZ.DO](http://amz.do) - キーワード順位を向上させ、商品出品にターゲットを絞ったトラフィックを誘導するために、主要なマーケットプレイスにわたって Amazon のスーパー URL、ASIN URL、ブランド URL、レビュー URL を生成する無料ツールです。クリック追跡と URL 履歴が含まれています。
- [Ad Genius](https://www.sellerlabs.com/ad-genius/?fp_ref=poly61) - Seller Labs の Ad Genius は、スポンサー広告キャンペーンを最適化し、入札管理を自動化し、広告効率と収益性を向上させるためのキーワードと ACoS のインサイトを明らかにする Amazon PPC 広告自動化ツールです。
- [Ecomhunt](https://www.ecomhunt.com/?afmc=4y2) - Ecomhunt は、トレンドで潜在性の高い商品を毎日厳選し、セラーが eコマースビジネスを立ち上げ成長させるのを支援するために、AI インサイト、市場データ、広告ターゲティング分析を提供します。

## 分析
- [ShopKeeper](https://shopkeeper.com/) - Shopkeeper は、売上、コスト、150 以上の Amazon 手数料を計算して真の利益をリアルタイムで表示する自動化された利益ダッシュボードです。Amazon、Shopify、Walmart、eBay、Etsy にわたるマルチマーケットプレイスのセラーに対応し、在庫予測とアラートを備えています。
- [HelloProfit](https://helloprofit.com/?ref=poly) - HelloProfit は、リアルタイムの売上追跡、利益レポート、マルチマーチャントダッシュボード、スポンサー広告の最適化を提供する Amazon セラー分析および PPC 管理プラットフォームです。商品レベルの分析、支払い内訳、顧客インサイト、PPC キャンペーンツールを単一のプラットフォームに統合します。
- [FeedbackWhiz](https://www.feedbackwhiz.com/) - 自動化されたレビュー／フィードバックのメールリクエスト、出品ハイジャッカーのアラート、利益／経費の追跡をカバーする Amazon および Walmart 向けオールインワンのセラープラットフォームです。主要な Amazon のグローバルマーケットプレイスすべてに対応しています。
- [Sellerboard](https://sellerboard.com/) - Sellerboard（旧 AMZcontrol）は、売上、コスト、純利益のリアルタイムダッシュボードを提供する Amazon セラー向けの利益分析プラットフォームです。在庫管理、PPC 入札の自動化、自動レビューリクエストメール、紛失在庫の返金追跡も含まれています。
- [Seller Labs Genius Bundle](https://sellerlabs.com?fp_ref=poly61) - Seller Labs は、レビュー自動化（Feedback Genius）、広告最適化（Ad Genius）、データ分析（Profit Genius）をカバーする Amazon セラーツールの統合スイートである Genius Bundle を提供します。Quantify 製品は名称が変更され、Profit Genius に統合されました。Profit Genius は Amazon の指標を一元化し、Google Sheets や Tableau などのツールと統合します。
- [Seller Labs Amazon MCP](https://www.sellerlabs.com/amazon-mcp/?fp_ref=poly61) - Seller Labs の Amazon MCP Server を使用すると、セラーは自然言語を使って Amazon のバックエンドデータをクエリして分析でき、面倒なレポートを会話型の分析に置き換えて、運用上の意思決定と最適化を加速します。
- [Seller Labs Data Hub](https://www.sellerlabs.com/data-hub/?fp_ref=poly61) - Seller Labs の Data Hub は、Amazon の売上、広告、利益の指標を統合された分析ワークスペースに一元化し、カスタムレポート用に Google Sheets や Tableau などのツールと統合します。

## 価格改定
- [Informed Repricer](https://www.informed.co/?ref=ponysmith3) - Informed Repricer は、競合価格を継続的に監視し、出品を調整してカートボックスを獲得し利益を伸ばす、自動化された Amazon 価格改定ツールです。カスタムの価格改定ルール、最小／最大価格の下限に対応し、Amazon のポリシーを遵守します。
- [ChannelMAX](http://www.channelmax.net/) - ChannelMAX は、カートボックスの獲得を最大化するためのリアルタイムのアルゴリズム価格改定に加え、FBA 返金回収、マルチチャネルの在庫同期、eBay などのチャネル向けのクロス出品ツールを提供する Amazon セラー管理プラットフォームです。
- [Seller Snap](https://sellersnap.io/) - 競合の動きを予測して価格競争を避け、利益を最大化するゲーム理論アルゴリズムに基づいて構築された、Amazon および Walmart セラー向けの AI 搭載価格改定ツールです。組み込みのセラー分析とともに 21 のマーケットプレイスに対応しています。
- [xSellco](https://www.xsellco.com/?utm_source=affiliate&utm_campaign=493ad7f6d045d3dcea1a399c4aa06d27&utm_medium=Link+Share) - xSellco は、Amazon、eBay、Walmart などの主要なマーケットプレイスにわたって、カスタマーサポート（eDesk）、自動価格改定、フィードバック／レビュー管理のためのツールを提供する、接続された eコマースプラットフォームです。
- [Sellery](https://sellerengine.com/) - Sellery は Amazon のリアルタイム価格改定ツールです。何百もの独自の価格組み合わせを可能にし、市場の状況に適応して価格戦略をパーソナライズします。市場を監視して変化に即座に反応するスマートフィルターにより、セラーは競争上の地位を向上させることができます。動的な純利益率管理、カスタマイズ可能な価格戦略、スケジュール化された価格改定、リアルタイムプレビューが含まれています。
- [AlphaRepricer](https://www.alpharepricer.com/) - 15 の Amazon マーケットプレイスにわたってカートボックスを獲得するために自動的に価格を調整する AI 搭載の Amazon 価格改定ツールです。ルールベースおよびアルゴリズム型の価格改定戦略、競合フィルタリング、分析を月額 25 ドルから提供します。
- [Feedvisor](https://feedvisor.com/) - Feedvisor の Agentis Commerce プラットフォームは、AI を使用して動的価格設定、スポンサー広告、在庫、競合インテリジェンスにわたる Amazon セラーの意思決定を統括します。カートボックスシェア、利益率、広告効率の統合的な最適化を求める大量販売セラーをターゲットにしています。
- [BQool Repricing Central](https://www.bqool.com/products/repricing-central/) - 利益率を保護しながらカートボックスを獲得するために複数のインテリジェントな戦略を使用する AI 搭載の Amazon 価格改定ツールです。自動化されたスケジュール価格改定、競合分析、詳細な分析とともに 9 つの Amazon マーケットプレイスに対応しています。
- [logicsale](https://www.logicsale.com/) - logicsale は、Amazon のカートボックスを獲得するための BuyBoxCatcher と、14 年の価格改定経験に裏打ちされた動的価格アルゴリズムを備えた、Amazon および eBay セラー向けの自動価格改定ツールです。契約不要の無料トライアルを提供しています。

## FBA 入荷
- [ReimburseOps](https://reimburseops.com/) - ReimburseOps は、セラーが Seller Central の CSV エクスポートをアップロードして、過少支払いや不一致を自動的に検出できるセルフサービスの FBA 返金監査ツールです。月額 19 ドル定額（手数料なし）で、申請可能なエクスポートと月次の自動再スキャンを提供します。
