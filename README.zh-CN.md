## 反馈与评论
- [AMZFinder](https://www.amzfinder.com/) - AMZFinder 是一个独立的 Amazon 卖家工具评测与对比平台。它围绕 8 大核心工作流（选品调研、关键词调研、Listing 优化、调价、PPC、数据分析等）对工具进行分类，用统一的评分卡为每款工具打分，并按卖家营收阶段推荐预设的工具组合——帮助卖家避免重复订阅，找到适合自己业务的工具。
- [FeedbackExpress](https://www.feedbackexpress.com/) - FeedbackExpress 帮助 Amazon 及多渠道卖家在 Amazon、eBay、Trustpilot 等多个市场上增加正面评论并管理反馈。它具备智能选择性索评、自动负面反馈处理，以及跨销售渠道集中管理评论的统一面板。
- [Feedbackwhiz](https://www.feedbackwhiz.com/) - 一站式 Amazon 与 Walmart 卖家平台，涵盖自动化评论/反馈邮件索取、Listing 跟卖者警报以及利润/费用追踪。支持所有主要的 Amazon 全球市场。
- [Feedback Genius](https://www.sellerlabs.com/products/feedback-genius/?fp_ref=poly61) - Seller Labs 旗下的 Feedback Genius 为 Amazon 卖家自动化符合 Amazon 规则的索评和卖家反馈触达。该工具使用预设或自定义模板发送自动化买家消息，为卖家节省人工跟进的时间。
- [xSellco](https://www.xsellco.com/feedback?utm_source=affiliate&utm_campaign=493ad7f6d045d3dcea1a399c4aa06d27&utm_medium=Link+Share) - xSellco 是一个互联的电商平台，提供跨 Amazon、eBay、Walmart 等主要市场的客户支持（eDesk）、自动化调价以及反馈/评论管理工具。

## 营销与优化
- [ZonGuru](https://zonguru.com/) - ZonGuru 是一个 AI 驱动的 Amazon 卖家平台，提供选品调研、Listing 优化、关键词追踪、业务指标和客户互动等工具。其 Helix Listing 工程功能利用智能体 AI，针对 Amazon 的 COSMO 和 Alexa for Shopping 发现算法进行优化。

- [River Cleaner](https://rivercleaner.com/) - River Cleaner 是一个 Chrome 扩展，让 Amazon 卖家能够自动优化产品 Listing。功能包括查找竞争对手的关键词、检查关键词是否被收录、删除重复关键词、找出表现最好和最差的 PPC 广告活动、为任意类目设置最大订购数量、按买家姓名查找订单、TOS 变更警报以及移动端 Listing 预览。River Cleaner 遵守 Amazon 的服务条款。
- [AMZDataStudio](https://amzdatastudio.com/) - AMZDataStudio 提供一套 Amazon 卖家工具，包括关键词排名追踪器、HTML Listing 转换器和关键词调研工具。它主要以免费 Chrome 扩展的形式发布，服务于 50,000 多名希望优化 Amazon Listing 并监控关键词收录情况的活跃用户。
- [SellerApp](https://www.sellerapp.com/) - SellerApp（前身为 SellerPrime）是一个一站式 Amazon 卖家平台，覆盖选品调研、关键词追踪、Listing 优化、PPC 管理以及跨 18+ 市场的利润分析。
- [Helium 10](https://i.helium10.com/c/1793920/3743859/37271) - Helium 10 工具旨在节省时间、找到有利可图的产品、发现高收益关键词、删除无用关键词、识别针对损坏/丢失库存的 FBA 赔偿，并优化产品 Listing。Helium 10 监控竞争对手并分析产品趋势，为商家创造机会以扩展其 Amazon 自有品牌业务。
- [AMZ.One](https://www.amz.one/) - AMZ.One 是一个一站式 Amazon 卖家平台，提供关键词排名追踪、Listing 优化分析、跟卖警报、负面评论通知以及竞争对手销售追踪。订阅套餐起价 $20/月，支持 17+ 个 Amazon 市场。
- [AMZBase](https://www.amzbase.com) - AMZBase 是一个面向 Amazon FBA 卖家的教育资源中心，精选第三方卖家工具并发布涵盖选品调研、关键词策略、Listing 优化和 AI 产品摄影的分步指南。它对 Jungle Scout 和 Helium 10 等工具进行深入评测，并提供可上手的工作流框架。
- [AMZBase Extension](https://chromewebstore.google.com/detail/amzbase-free-amazon-produ/nhebfnlghmjfcammdgbgfcomeonbfcfn) - 一个用于 Amazon 选品调研的免费 Chrome 扩展，直接在 Amazon 搜索和类目页面上叠加显示 ASIN、Best Sellers Rank、FBA 报价和卖家数量。将鼠标悬停在产品图片上可预览 CamelCamelCamel 价格历史和 Keepa 排名历史图表。支持 20+ 个 Amazon 市场。
- [AMZ.DO](http://amz.do) - 一款免费工具，可在主要市场上生成 Amazon super URL、ASIN URL、品牌 URL 和评论 URL，以提升关键词排名并为产品 Listing 引入精准流量。包含点击追踪和 URL 历史记录。
- [Ad Genius](https://www.sellerlabs.com/ad-genius/?fp_ref=poly61) - Seller Labs 旗下的 Ad Genius 是一款 Amazon PPC 广告自动化工具，可优化 sponsored 广告活动、自动管理出价，并呈现关键词和 ACoS 洞察，以提升广告效率和盈利能力。
- [Ecomhunt](https://www.ecomhunt.com/?afmc=4y2) - Ecomhunt 每日精选热门和高潜力产品，提供 AI 洞察、市场数据和广告定向分析，帮助卖家启动并发展其电商业务。

- [Seller Labs Genius Bundle](https://sellerlabs.com?fp_ref=poly61) - Seller Labs 提供 Genius Bundle，这是一套集成的 Amazon 卖家工具，涵盖评论自动化（Feedback Genius）、广告优化（Ad Genius）和数据分析（Profit Genius）。Quantify 产品已重新命名并整合进 Profit Genius，后者集中管理 Amazon 指标并与 Google Sheets 和 Tableau 等工具集成。

- [Seller Labs Data Hub](https://www.sellerlabs.com/data-hub/?fp_ref=poly61) - Seller Labs 旗下的 Data Hub 将 Amazon 销售、广告和利润指标集中到一个统一的分析工作区，并与 Google Sheets 和 Tableau 等工具集成以实现自定义报告。
